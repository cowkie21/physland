# PhysLand (Node.js + PostgreSQL)

- `server.js` — сервер и API (`/api/...`), раздаёт сайт 
- `schema.sql` — таблицы базы (создаются автоматически при запуске)
- `shared-*.js` — задачи, ключи ответов, проверка ответов (остаются только на сервере)
- `index.html` — сам сайт
- `bot/` — Telegram-бот (Python, aiogram 3): рейтинг, добавление достижений, уведомления о верификации

Переменные окружения:
- `DATABASE_URL` — адрес базы PostgreSQL (обязательно)
- `ADMIN_EMAIL`, `ADMIN_PASSWORD` — логин и пароль администратора (создаётся при первом запуске)
- `SEED_DEMO=1` — добавить демо-учеников (по желанию)

- `TELEGRAM_BOT_USERNAME` — имя бота без @ (для кнопки «Открыть бота» в кабинете, по желанию)

Запуск у себя: `npm install`, затем `DATABASE_URL=... node server.js` и откройте http://localhost:3000

## Telegram-бот

1. Создайте бота у @BotFather и получите токен.
2. Запустите сайт (`node server.js`) — он создаст новые таблицы (`achievements`, `telegram_links`, `telegram_codes`, view `ratings`).
3. Запустите бота (нужен Python 3.10+):
   ```
   cd bot
   pip install -r requirements.txt
   BOT_TOKEN=... DATABASE_URL=... python bot.py
   ```
   Для бота и сайта `DATABASE_URL` одинаковый. Запускать нужно один экземпляр бота.
4. Ученик: кабинет → «Достижения» → «Получить код подключения» → отправить код боту (или перейти по ссылке).
5. Администратор: админ-панель → «Достижения» → «Подтвердить» / «Отклонить» — бот пришлёт ученику уведомление (в течение ~10 секунд).

Рейтинг = XP с сайта + 20 XP за каждое подтверждённое достижение.
